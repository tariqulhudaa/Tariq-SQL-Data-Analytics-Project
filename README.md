**SQL-Data-Analytics-Project**

A SQL Server (T-SQL) analytics project built on a retail bike sales dataset, modeled as a classic star schema (one fact table, two dimension tables). The goal is to practice and showcase core data-analyst SQL skills — schema design, data quality checks, joins, aggregation, window functions, and business-question-driven analysis — on realistic, denormalized retail data.

**Overview**

This project takes three raw CSV extracts — customers, products, and sales transactions — and turns them into a queryable star schema in SQL Server, then answers a set of realistic business questions with SQL Server: revenue trends, customer value, product performance, and segment breakdowns by country and gender.

**Tool Used**

SQL Server/ SQL Server Management Studio (SSMS)
